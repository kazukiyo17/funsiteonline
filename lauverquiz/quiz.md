# Laufey 精选曲目｜人格象限测试（四维度精准匹配）

## 核心设计逻辑
将 **20 首** Laufey 原创 / 录音室主线曲目，按 **4 大人格维度** 分组（各组曲目数量见下）；  
每题 4 选项对应 4 维度，做完统计 4 维度总分，**分数最高的维度** → 在该维度曲目池中，用子题加权算出 **唯一本命曲**，每首歌对应专属灵魂人设。

**曲目池说明（与线上 `songs-meta.json` 一致）**

| 维度 | 曲目数 | 备注 |
|------|--------|------|
| A 怀旧沉溺 | 5 首 | |
| B 浪漫理想 | 4 首 | |
| C 秩序克制 | 5 首 | |
| D 自我觉醒 | 6 首 | |

已从题库剔除（不参与结果匹配）：翻唱标准曲 / 非主线收录 **Seems Like Old Times**；Sting 谱系翻唱 **Fragile (Jazz Version)**、**While You Were Sleeping (Jazz Version)**；以及无词人声器乐 **Cuckoo Ballet (Interlude)**。

   （代表：Clockwork / Falling Behind / Silver Lining / Bored / Promise）

## 测试规则
1. 共 16 题，每题 4 个选项，分别对应 4 个维度：  
   - 选 A = +1「怀旧沉溺」  
   - 选 B = +1「浪漫理想」  
   - 选 C = +1「秩序克制」  
   - 选 D = +1「自我觉醒」
2. 16 题完成后，统计 4 个维度的总得分。
3. **得分最高的维度** → 进入该维度曲目池，用「组内子题」算出池中 **得分最高的一首**，即为你的专属人格主题曲。

## 整体逻辑
1. 16 题，每题 4 选项 → 计入 **怀旧 / 浪漫 / 秩序 / 觉醒** 四大分箱。  
2. 取 **总分最高** 的维度（平局时按 A→B→C→D 优先，与实现一致）。  
3. 在该维度 **曲目列表** 上，用预先固定的 **4 道子题** 做组内加权，**累积分最高的一首** 为结果。

## 二、核心计算规则

### 第一步：算大类
- 每题：选 A +1 怀旧 / B +1 浪漫 / C +1 秩序 / D +1 觉醒  
- 四维总分 **最高者** = 进入该大类  

### 第二步：子题归属（组内打分只用这 4 题）
| 维度 | 子题编号 |
|------|-----------|
| A 怀旧 | Q1, Q3, Q5, Q7 |
| B 浪漫 | Q2, Q4, Q6, Q8 |
| C 秩序 | Q9, Q10, Q11, Q12 |
| D 觉醒 | Q13, Q14, Q15, Q16 |

### 第三步：组内曲目加权（4 选 → 映射至多前 4 首歌）
对某一维度，设该组曲目按固定顺序为 **歌 1 … 歌 N**（N 为 4、5 或 6，见上表）。

在这 **4 道子题** 的每一题上：
- 若用户选 **A / B / C / D**，分别视为选项序号 **1 / 2 / 3 / 4**，对应 **歌 1～歌 4** 中索引与之对齐的一首：**该首 +2 分**，同题内 **其余各首 +1 分**（含歌 5、歌 6…）。  
- 若该组 **仅有 4 首歌**（B 维），则四首歌都在「前四」映射内，无额外「仅 +1 保底」位；规则仍为上式（每题恰有一首 +2、三首 +1）。

**4 题累加完毕后，该组内总分最高的歌曲 = 你的本命单曲**（同分取列表顺序靠前者，与实现一致）。

## 三、落地计算模板（摘要）

### 1）维度计分
- 怀旧(A)：16 题中选 A 的次数  
- 浪漫(B)：选 B 的次数  
- 秩序(C)：选 C 的次数  
- 觉醒(D)：选 D 的次数  
👉 取最大，进入该组  

### 2）组内子题
- 怀旧：Q1, Q3, Q5, Q7  
- 浪漫：Q2, Q4, Q6, Q8  
- 秩序：Q9–Q12  
- 觉醒：Q13–Q16  

### 3）组内打分（与程序一致）
每道子题：选项 A/B/C/D → 歌 1～4 中对应下标 **+2**，该题其它歌各 **+1**；若存在 **歌 5、歌 6**，每题对它们各 **+1**（不因选项而改变）。

## 四、举例（怀旧组 A，共 5 首歌）

曲目顺序：① Carousel ② Forget‑Me‑Not ③ Too Little, Too Late ④ Castle in Hollywood ⑤ Letter To My 13 Year Old Self  

用 Q1、Q3、Q5、Q7 打分：

- Q1 选 **A** → ① +2，②③④⑤ 各 +1  
- Q3 选 **C** → ③ +2，①②④⑤ 各 +1  
- Q5 选 **D** → ④ +2，①②③⑤ 各 +1  
- Q7 选 **B** → ② +2，①③④⑤ 各 +1  

累加后比较 ①～⑤ 总分，最高者即为结果。
